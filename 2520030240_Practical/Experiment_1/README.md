# Experiment 1: Investigating Hardware Resources and OS Services

## Aim
To study how the operating system abstracts hardware resources such as CPU, memory, storage, and I/O devices using Linux commands.

## Commands Used

1. uname -a
   - Displays operating system information, kernel version, and architecture.

2. lscpu
   - Displays CPU architecture, processor model, and CPU details.

3. lsblk
   - Displays storage devices and partitions.

4. ps -ef
   - Displays all running processes and their parent process IDs.

5. top
   - Displays real-time CPU, memory usage, and running processes.

6. free -h
   - Displays memory usage in a human-readable format.

## Conclusion
The operating system abstracts hardware resources by providing a simple interface for applications to use the CPU, memory, storage, and I/O devices without interacting with the hardware directly.
